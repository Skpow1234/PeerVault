# API Analytics Examples

This guide provides practical examples for using the PeerVault API Analytics system.

## Basic Usage

This document focuses on analytics concepts and endpoints. Command-line examples have been removed to keep the workflow Docker-only.

Use the following endpoints to explore analytics:

- `/api/v1/analytics/summary`
- `/api/v1/analytics/dashboard`
- `/api/v1/analytics/usage`
- `/api/v1/analytics/trends`
- `/api/v1/analytics/popularity`
- `/api/v1/analytics/endpoint`
- `/api/v1/analytics/user`
- `/api/v1/analytics/calls`
